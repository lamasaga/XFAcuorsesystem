# 智能排课系统 — 使用指南

> **适用对象**：教务老师、排课负责人、A-Level 课程管理员  
> **最后更新**：2026-05-18  
> **说明**：本指南只介绍在网页上如何操作，不涉及程序安装与开发内容。

---

## 一、这个系统能做什么

　　这是学校使用的**课表编排与管理**网页系统，主要用来：

- **行政班课表**：录入教师、班级、课程安排后，由系统自动排出本学期课表  
- **A-Level 选修**（G10–G12）：管理选修科目、学生选课、课程班，并与行政课表一起查看  
- **查看与调整课表**：按班级、教师、学生等角度查看；可对比多个方案并选定正式课表  
- **导入与导出**：用 Excel 模板批量录入基础信息，把课表导出为文件发给老师  

　　打开学校提供的网址即可使用（目前无需单独登录账号）。

---

## 二、如何进入系统

### 打开网页

1. 打开浏览器（建议使用 **Chrome** 或 **Edge** 较新版本）。  
2. 在地址栏输入学校提供的网址（例如：`http://82.156.225.73`，以学校通知为准）。  
3. 回车后进入系统首页。

### 查看本帮助

- 点击页面右上角 **「帮助」**；或  
- 在 **首页** 的「快速操作」里点击 **「使用帮助」**。  

　　帮助内容与本说明一致，可随时查阅。

### 首次打开较慢时

　　若出现「正在连接…」提示且时间较长，可先 **刷新页面**（F5）；仍无法进入时，请联系学校负责维护系统的老师或信息技术部门。

## 三、页面菜单说明

　　登录系统后，顶部菜单从左到右依次为：

| 菜单 | 您会用到它做什么 |
|------|------------------|
| **首页** | 查看整体数据概况、常用快捷入口 |
| **数据管理** | 维护教师、班级、科目、行政课程、分层课、场地等基础信息 |
| **A-Level** | 管理高中选修：学生、科目、选课、课程班 |
| **约束设置** | 调整排课规则（如主科尽量上午）；一般可保持默认 |
| **自动排课** | 按向导检查数据、设置参数、生成课表方案 |
| **课表管理** | 查看课表、选定正式方案、按班级/教师等切换查看 |
| **导出** | 把课表导出为文件 |

　　页面底部会显示当前系统中的教师、班级、科目等数量，便于大致核对数据是否齐全。

## 四、行政班排课：推荐操作顺序

　　每学期排课，建议按下面顺序做，减少漏填、排不出来的情况。

```text
① 在「数据管理」里把基础信息准备好
      ↓
②（可选）在「约束设置」里确认规则，首次使用可不改
      ↓
③ 在「自动排课」里生成课表方案
      ↓
④ 在「课表管理」里对比方案 → 选定「使用中」的正式课表
      ↓
⑤ 在「导出」里导出课表，发给班主任或任课教师
```

### 4.1 第一步：数据管理

　　点顶部 **数据管理**，左侧切换不同卡片，逐项完成（也可用各页面的 **导入** 按钮，先下载模板再填写上传）：

| 页面 | 您需要做什么 | 小提示 |
|------|--------------|--------|
| **教师管理** | 录入教师姓名、中教/外教、任教科目、每周最多上几节课等 | 可设置哪天第几节不能上课、早班/晚班 |
| **班级管理** | 录入年级、班型（国际班 I / 综素班 N）、班主任 | 新学年时可用 **一键升班** |
| **科目管理** | 录入科目名称、是否主科、是否需要专用教室等 | 主科会影响「尽量排在上午」等规则 |
| **行政课程** | 指定「哪位老师给哪个班上什么课、每周几节」 | 可勾选是否需要连堂（两节连上） |
| **分层课程** | 设置分层课或合班课（如数学分层、两班合班上体育） | 分层时各层要在同一时间上课 |
| **场地资源** | 录入专用教室（美术室、体育馆等）及能容纳几个班同时使用 | 与需要专用教室的科目对应 |

### 4.2 第二步：约束设置（可选）

　　进入 **约束设置** 可打开或关闭一些排课偏好，例如：

- 同一班级同一天同一科目不超过 2 节  
- 语文、数学、英语等主科尽量排在上午  
- 体育课、艺术课尽量不排在第一节  
- 教研组固定开会时间等  

　　**第一次使用建议保持默认**，排不通或结果不理想时再请熟悉系统的同事一起调整。

### 4.3 第三步：自动排课

　　进入 **自动排课**，按屏幕上的四步向导操作：

1. **数据检查**  
   - 系统会检查教师、班级、课程等是否齐全。  
   - 若有红色或未通过项，回到 **数据管理** 补全后再排。  

2. **参数设置**  
   - **排课范围**：一般选「全校排课」；若只需部分年级/班级，按界面勾选（以实际可选为准）。  
   - **优化程度**：数字越大排得越细，但等待时间越长；日常可先用中间档位。  
   - **方案数量**：可一次生成 1 个或多个方案，便于对比。  

3. **开始排课**  
   - 点击开始后等待进度完成；全校排课可能需要几分钟，请勿关闭页面。  

4. **结果确认**  
   - 查看各方案的得分、主科上午比例等，选定较满意的一个进入下一步。  

### 4.4 第四步：课表管理

- 在页面顶部 **选择课表方案**（一次排课可能产生多个方案）。  
- 对要采用的方案点击 **设为使用**，即为本学期 **正式课表**。  
- 切换 **班级 / 教师 / 场地 / 学生** 等视图查看。  
- 需要纸质或文件时，可点 **打印** 或到 **导出** 页面下载。  

### 4.5 第五步：导出

1. 进入 **导出**。  
2. 选择要导出的 **课表**（应与「课表管理」里「使用中」的一致）。  
3. 选择 **全部班级**、**某个班级** 或 **某位教师**。  
4. 选择 **CSV** 等可用格式，下载后可用 Excel 打开。

## 五、A-Level（G10–G12）操作顺序

　　A-Level 与行政班在同一次 **自动排课** 中完成：先排好行政课，再在空余时段排选修课。

```text
① A-Level → 科目管理
      ↓
② A-Level → 学生管理
      ↓
③ A-Level → 选课管理
      ↓
④ A-Level → 课程班管理（建班、指定老师、加入学生）
      ↓
⑤ 自动排课（与行政班相同入口）
      ↓
⑥ 课表管理 → 按「学生」查看（行政课 + 选修课）
```

### 5.1 科目管理

- 录入或导入 A-Level 科目（如考试局、AS/A2、每周课时等）。  

### 5.2 学生管理

- 录入 G10–G12 学生学号、姓名、年级、所属行政班。  
- 新学年可用 **一键升年级**；毕业班注意更新为「毕业」等状态。  

### 5.3 选课管理

- 点 **新建选课**，选择学生、学年、学期。  
- 在下方 **添加科目**（可设优先级）。  
- 点 **保存** 即完成，**无需再点审批**。  

### 5.4 课程班管理

- 为每门开设的科目建立 **课程班**（班名、容量、授课教师、学年学期）。  
- 在课程班中 **添加学生**（应与选课结果一致）。  
- **必须指定授课教师**，该班才会参与自动排课。  

### 5.5 查看课表

- 与行政班一样，在 **自动排课** 中统一生成。  
- 在 **课表管理** 中选 **学生** 视图，可看某位学生行政课与选修课合计。

## 六、日常操作说明

### 6.1 列表页的通用按钮

| 按钮/操作 | 含义 |
|-----------|------|
| **新建** | 增加一条记录 |
| **编辑** | 修改已有记录 |
| **删除** | 从列表中去掉（一般可恢复需联系管理员） |
| **导入** | 下载 Excel 模板 → 填好 → 上传 |
| **筛选** | 列表上方下拉框，选完后自动刷新 |

　　表单中带红色 **\*** 的为必填项。

### 6.2 教师「不能排课的时间」与早班/晚班

- 在 **教师管理** 编辑教师时，可标明某些节次不上课。  
- **早班**：全天可排；**晚班**：上午一般不排（按学校规定在界面选择）。  
- 若不熟悉高级设置，可先只填早班/晚班，其余留空。  

### 6.3 连堂课

- 在 **行政课程** 或 **分层课程** 里勾选「连堂」时，系统会安排 **每周一次连续两节**，其余课时为单节（在周课时不少于 2 节的前提下）。  

### 6.4 分层课与合班课

| 类型 | 通俗理解 |
|------|----------|
| **分层** | 同年级学生按水平分成几层，同时上课，每层一位老师 |
| **合班** | 两个或多个行政班合并在一起由一位老师上课 |

### 6.5 什么是「课表方案」和「使用中」

- 每次点 **自动排课** 会生成一套带日期的 **方案**，可保留多套以便对比。  
- 只有标记为 **使用中** 的那套，才是学校当前采用的 **正式课表**，导出时也应选这套。  
- 不需要的旧方案可在 **课表管理** 中删除。

## 七、遇到问题时可以怎么做

| 您看到的情况 | 建议处理方式 |
|--------------|--------------|
| 提示排课失败、无解 | 回到 **约束设置** 看是否规则过严；检查教师周课时是否过多、分层课是否漏配 |
| 等了很久还在排 | 优化程度选低一档再试；全校数据多时需要耐心等候 |
| 有的课没排进去 | 检查该教师是否标了「不能上课」、专用教室是否够用、班级总课时是否超出 |
| 页面空白或刷新后打不开 | 按 **Ctrl + Shift + R** 强制刷新；换 Chrome/Edge 再试 |
| 提示无法连接、一直加载 | 刷新页面；仍不行请联系学校信息技术老师 |
| 不知道现在用的是哪套课表 | 打开 **课表管理**，名称旁有 **(使用中)** 的就是正式课表 |

## 八、Excel 导入时注意

1. **先小批量试**：例如先导入一个班、几名教师，排课试跑成功后再全量导入。  
2. **名称要一致**：模板里的科目名、学号等须与系统里已有写法完全相同。  
3. **分层课导入后**：到 **分层课程** 和 **行政课程** 页面看一眼是否班级、老师都已对应。  
4. **选课导入**：按最新模板填写即可，保存后即有效，无需再填「状态」列。

## 十、常见问题

**问：选课保存后还要审批吗？**  
答：不需要。保存后即为有效选课，可继续建课程班并排课。

**问：排课可以只做某一个年级吗？**  
答：界面上可选择范围；若选后仍像全校一样，可先使用全校排课，或向信息技术老师反馈需求。

**问：A-Level 课表节数不对怎么办？**  
答：请检查：① 科目里的 **周课时** 是否填对；② 课程班是否 **指定了教师**；③ 班内是否 **加入了学生**。

**问：几个人可以同时改数据吗？**  
答：可以，但同时改容易互相覆盖。建议排课关键阶段由一人主录，完成后再开放。

**问：帮助在哪里？**  
答：右上角 **帮助**，或首页 **使用帮助**。
