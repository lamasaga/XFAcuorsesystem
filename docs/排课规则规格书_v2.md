## 一、学校基础数据结构

### 1.1 班级体系

```yaml
班级分类:
  I类 (国际班):
    年级范围: PK, KG, G1-G11
    班级数量:
      - PK: 1个班 (IPK-1)
      - KG: 1个班 (IKG-1) 
      - G1-G9: 每年级2个班 (IG1-1, IG1-2, ..., IG9-1, IG9-2)
      - G10: 1个班 (IG10-1)
      - G11: 1个班 (IG11-1)
    总计: 1 + 1 + 9×2 + 1 + 1 = 22个班
    
  N类 (综素班):
    年级范围: G1-G9
    班级数量: 每年级1个班 (NG1-1, NG2-1, ..., NG9-1)
    总计: 9个班

  全校总计: 31个班（可在系统中动态配置）
```

### 1.2 作息时间结构

```yaml
每日课程安排:
  上午: 5节课 (第1-5节)
  下午: 4节课 (第6-9节)
  
  特殊时段标记:
    - 第5节: 午餐前 (BEFORE_LUNCH)
    - 第6节: 午餐后 (AFTER_LUNCH)  
    - 第9节: 晚饭前 (BEFORE_DINNER)

每周安排:
  周一至周四: 9节课 (第1-9节)
  周五: 7节课 (第1-5节 + 第6-7节，下午只上2节)
  
  总时间槽: 4×9 + 7 = 43个时间槽/周
```

### 1.3 教师分类与标签系统

```yaml
教师属性:
  基本信息:
    - id: 教师ID
    - name: 姓名

  标签系统 (tags):
    - 班主任: HOMEROOM_TEACHER
    - 副班主任: ASSISTANT_HOMEROOM
    - 小学管理干部: PRIMARY_ADMIN
    - 中学管理干部: SECONDARY_ADMIN

  班次状态 (每日):
    - 早班: MORNING_SHIFT (8:00-17:00)
    - 晚班: EVENING_SHIFT (12:00-20:00)
    
  可用时间约束:
    - 早班: 第1-9节均可排课

    - 晚班-初中教师: 第5-9节可排课（特例：可排第5节）
```

## 二、硬约束规则（必须满足）

### 2.1 基础冲突约束

```yaml
规则ID: BASIC_001
名称: 教师时间冲突
描述: 同一教师在同一时间槽只能上一节课
类型: 硬约束
优先级: 最高

规则ID: BASIC_002  
名称: 班级时间冲突
描述: 同一班级在同一时间槽只能上一节课
类型: 硬约束
优先级: 最高

规则ID: BASIC_003
名称: 周课时满足
描述: 每个班级的各科目周课时数必须满足教学计划
类型: 硬约束
优先级: 最高
```

### 2.2 早晚班约束

```yaml
规则ID: SHIFT_001
名称: 晚班教师排课限制
类型: 硬约束

逻辑:
  IF 教师.当日班次 == "晚班" THEN
    IF 教师.department == "小学部" THEN
      该教师当日只能安排在 第6-9节
    ELSE IF 教师.department == "中学部" THEN
      该教师当日只能安排在 第5-9节  # 特例：可排第5节
    END
  END

规则ID: SHIFT_002
名称: 班主任晚班互斥
类型: 硬约束

逻辑:
  IF 班级.中教班主任 AND 班级.外教班主任 THEN
    两人不能在同一天都安排晚班
  END

规则ID: SHIFT_003
名称: 中教班主任周一晚班限制
类型: 硬约束

逻辑:
  IF 教师.tags 包含 "班主任" AND 教师.type == "中教" THEN
    周一不安排该教师晚班
  END

规则ID: SHIFT_004
名称: 晚班均匀分配
类型: 软约束（但要尽量满足）

逻辑:
  - 每天需要足够的晚班教师盯晚自习
  - 晚班在所有教师中均匀分配
  - 考虑教师周课时量
```

### 2.3 分层教学约束

```yaml
规则ID: LAYER_001
名称: 分层课时间同步
类型: 硬约束

核心原则: 同一分层组的所有层级必须安排在完全相同的时间槽

分层配置:

  数学分层 (G3及以上):
    - 适用年级: G3, G4, G5, G6, G7, G8, G9
    - 分层方式: 同年级内分2层
    - 涉及班级: 该年级所有I类和N类班级
    - 约束: 同年级的2层数学课必须在相同时间槽
    
  语文分层 (G4及以上):
    - 适用年级: G4, G5, G6, G7, G8, G9
    - 分层方式: 同年级内分2层
    - 涉及班级: 该年级所有I类和N类班级
    - 约束: 同年级的2层语文课必须在相同时间槽
    
  英语分层:
    组1 - G3至G5 (同年级分层):
      - 分层方式: 每个年级内分2层
      - 约束: 同年级的2层英语课必须在相同时间槽
      
    组2 - G6至G7 (跨年级分层):
      - 涉及年级: G6, G7
      - 分层数: 7层
      - 约束: 所有7层英语课必须在完全相同的时间槽
      - 注意: 这7层课占用7个教师在同一时间
      
    组3 - G8至G9 (跨年级分层):
      - 涉及年级: G8, G9
      - 分层数: 6层
      - 约束: 所有6层英语课必须在完全相同的时间槽

分层排课策略:
  1. 分层课是"原子操作"，必须整体一起安排
  2. 排课时，先为分层课组找到可行时间槽
  3. 跨年级分层（如G6-G7英语7层）需要7个时间槽同时可用
  4. 分层课的连堂要求也必须满足
```

## 五、排课算法设计

### 5.1 问题复杂度分析

```
问题规模估算:
- 班级数: ~31个
- 时间槽: ~43个/周
- 教师数: ~50-80人
- 课程数/班: ~40节/周
- 总课程数: 31 × 40 = 1240节/周

约束复杂度:
- 分层课约束: 跨班级、跨教师的强耦合
- 场地容量: 全局资源竞争
- 早晚班: 时变约束（每天不同）
- 连堂课: 相邻时间槽绑定

结论: 这是一个高度耦合的约束满足问题，需要分阶段处理
```

### 5.3 关键算法细节

#### 5.3.1 分层课排课算法

```python
def schedule_layer_groups(layer_groups, teachers, time_slots, constraints):
    """
    为所有分层组安排时间
    核心难点: 跨年级分层（如G6-G7英语7层）需要7个教师同时可用
    """
    
    # 按复杂度排序：跨年级优先，层数多优先
    sorted_groups = sort_by_complexity(layer_groups)
    
    for group in sorted_groups:
        # 获取该分层组的所有教师
        group_teachers = [task.teacher for task in group.tasks]
        
        # 需要安排的课时数
        hours_to_schedule = group.weekly_hours
        continuous_required = group.needs_continuous
        
        # 寻找所有教师同时可用的时间槽
        available_slots = find_common_available_slots(
            group_teachers, 
            time_slots,
            constraints
        )
        
        if len(available_slots) < hours_to_schedule:
            raise ConstraintViolation(f"分层组 {group.id} 无法找到足够的共同可用时间")
        
        # 如果需要连堂，优先寻找连续时间槽
        if continuous_required:
            continuous_slots = find_continuous_slots(available_slots, 2)
            # 安排连堂
            assign_continuous(group, continuous_slots[0])
            hours_to_schedule -= 2
            
        # 安排剩余课时
        for slot in select_best_slots(available_slots, hours_to_schedule):
            assign_slot(group, slot)
```

#### 5.3.2 场地容量检查

```python
def check_venue_capacity(schedule, time_slot, subject, venue_resources):
    """
    检查在指定时间槽，该科目的场地是否还有容量
    """
    venue = get_venue_for_subject(subject, venue_resources)
    if venue is None:
        return True  # 该科目不需要特殊场地
    
    # 统计该时间槽已安排的同场地课程数
    current_count = count_scheduled_classes(schedule, time_slot, venue.subjects)
    
    return current_count < venue.capacity
```

#### 5.3.3 早晚班均衡分配

```python
def assign_shifts(teachers, days, constraints):
    """
    为教师分配每日班次
    目标: 均衡分配，满足约束
    """
    
    # 计算每位教师需要的晚班天数（基于课时量）
    for teacher in teachers:
        teacher.evening_shift_days = calculate_evening_shifts(teacher)
    
    # 每天需要的晚班教师数
    daily_evening_quota = calculate_daily_quota()
    
    for day in days:
        evening_candidates = get_evening_candidates(teachers, day, constraints)
        
        # 排除班主任周一约束
        if day == MONDAY:
            evening_candidates = [t for t in evening_candidates 
                                  if not (t.is_homeroom and t.type == 'CN')]
        
        # 贪心选择晚班教师
        selected = select_evening_teachers(
            evening_candidates, 
            daily_evening_quota,
            balance_score  # 优先选择晚班天数还不够的教师
        )
        
        # 检查班主任互斥约束
        validate_homeroom_mutual_exclusion(selected)
        
        assign_shifts_for_day(teachers, day, selected)
```

### 5.4 算法复杂度与优化

```yaml
时间复杂度分析:
  - 分层课排课: O(G × S × T)  # G=分层组数, S=时间槽数, T=组内教师数
  - 场地受限课: O(C × S × V)  # C=班级数, S=时间槽数, V=场地检查
  - 普通课排课: O(N × S)      # N=课程数, S=时间槽数
  - 全局优化: O(I × N)        # I=迭代次数, N=邻域大小

优化策略:
  1. 约束传播: 提前剪枝不可能的时间槽
  2. 缓存计算: 缓存教师可用时间、场地占用情况
  3. 增量更新: 调整时只重新计算受影响的约束
  4. 并行计算: 分层组之间可以并行尝试
```
