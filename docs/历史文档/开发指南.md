## 一、问题域分析

### 1.1 为什么这个排课问题特别难

| 复杂度来源 | 说明 | 难度 |
|-----------|------|------|
| **分层教学** | 多班学生打乱重组成多层，所有层必须同一时间上课 | ⭐⭐⭐ |
| **早晚班** | 教师可用时间取决于当天班次，且班次分配有约束 | ⭐⭐⭐ |
| **场地容量** | 体育≤4班、美术≤2班、声乐/钢琴≤1班同时上课 | ⭐⭐ |
| **连堂课** | 语数英至少1次连堂，小学美术必连堂，不能跨午休 | ⭐⭐ |
| **会议预留** | 27个教研组各需2节连续时间，管理干部有固定会议 | ⭐⭐ |

### 1.2 问题规模

```
班级数:      31个（22个I类 + 9个N类）
时间槽:      43个/周（周一至周四9节 + 周五7节）
教师数:      50-80人
总课程数:    约1240节/周（31班 × 40节）
搜索空间:    ≈ 10^100+（NP-Hard 问题）
```

### 1.3 常规算法为什么行不通

| 方法 | 问题 |
|------|------|
| 纯遗传算法 | 分层约束是硬绑定，随机变异99%会违反约束 |
| 纯回溯算法 | 搜索空间太大，分层课导致大量剪枝失败 |
| 整数规划 | 变量数爆炸，求解器超时 |
| 简单贪心 | 前期决策错误，后期无法补救，经常无解 |

**解决方案**: 分阶段约束满足策略（详见第四节）

### 3.2 核心数据表 SQL

```sql
-- ========================================
-- 班级表
-- ========================================
CREATE TABLE classes (
    id              SERIAL PRIMARY KEY,
    name            VARCHAR(20) NOT NULL,           -- 如: IG3-1, NG2-1
    type            VARCHAR(1) NOT NULL,            -- I=国际班, N=综素班
    grade           VARCHAR(10) NOT NULL,           -- PK/KG/G1-G11
    class_no        INTEGER NOT NULL,
    department      VARCHAR(20) NOT NULL,           -- PRIMARY/SECONDARY
    homeroom_cn_id  INTEGER REFERENCES teachers(id), -- 中教班主任
    homeroom_en_id  INTEGER REFERENCES teachers(id), -- 外教班主任
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(type, grade, class_no)
);

-- ========================================
-- 教师表
-- ========================================
CREATE TABLE teachers (
    id              SERIAL PRIMARY KEY,
    name            VARCHAR(50) NOT NULL,
    type            VARCHAR(2) NOT NULL,            -- CN=中教, EN=外教
    department      VARCHAR(20) NOT NULL,           -- PRIMARY/SECONDARY
    tags            TEXT[],                         -- 标签: HOMEROOM_TEACHER, PRIMARY_ADMIN等
    subjects        TEXT[],                         -- 可教科目
    max_weekly_hours INTEGER DEFAULT 25,
    unavailable_slots JSONB,                        -- 不可用时间槽
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- ========================================
-- 科目表
-- ========================================
CREATE TABLE subjects (
    id              SERIAL PRIMARY KEY,
    code            VARCHAR(20) UNIQUE NOT NULL,
    name            VARCHAR(50) NOT NULL,
    category        VARCHAR(20),                    -- 文化课/艺术/体育/综合
    is_main         BOOLEAN DEFAULT false,          -- 是否主科
    required_room_type VARCHAR(30),                 -- 所需教室类型
    color           VARCHAR(10),
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- ========================================
-- 分层组表
-- ========================================
CREATE TABLE layer_groups (
    id              SERIAL PRIMARY KEY,
    subject_id      INTEGER REFERENCES subjects(id),
    grades          TEXT[] NOT NULL,                -- 涉及年级
    layer_count     INTEGER NOT NULL,               -- 分层数
    is_cross_grade  BOOLEAN DEFAULT false,          -- 是否跨年级
    weekly_hours    INTEGER NOT NULL,
    continuous_required BOOLEAN DEFAULT false,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- ========================================
-- 教学任务表
-- ========================================
CREATE TABLE teaching_tasks (
    id              SERIAL PRIMARY KEY,
    semester_id     INTEGER REFERENCES semesters(id),
    teacher_id      INTEGER REFERENCES teachers(id),
    class_id        INTEGER REFERENCES classes(id),
    subject_id      INTEGER REFERENCES subjects(id),
    weekly_hours    INTEGER NOT NULL,
    is_continuous   BOOLEAN DEFAULT false,
    continuous_count INTEGER DEFAULT 1,
    layer_group_id  INTEGER REFERENCES layer_groups(id), -- 可选
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(semester_id, teacher_id, class_id, subject_id)
);

-- ========================================
-- 课表条目表
-- ========================================
CREATE TABLE schedule_entries (
    id              SERIAL PRIMARY KEY,
    task_id         INTEGER REFERENCES teaching_tasks(id),
    day_of_week     INTEGER NOT NULL,               -- 1-5
    period          INTEGER NOT NULL,               -- 1-9
    room_id         INTEGER REFERENCES rooms(id),
    is_locked       BOOLEAN DEFAULT false,
    is_part_of_continuous BOOLEAN DEFAULT false,
    continuous_position INTEGER,                    -- 连堂位置 1/2
    version         INTEGER DEFAULT 1,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(task_id, day_of_week, period)
);

-- ========================================
-- 场地资源表
-- ========================================
CREATE TABLE venue_resources (
    id              SERIAL PRIMARY KEY,
    name            VARCHAR(50) NOT NULL,
    capacity        INTEGER NOT NULL,               -- 同时最大班数
    subjects        TEXT[] NOT NULL,                -- 关联科目
    applicable_grades TEXT[],                       -- 适用年级
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- ========================================
-- 教师每日班次表
-- ========================================
CREATE TABLE daily_shifts (
    id              SERIAL PRIMARY KEY,
    teacher_id      INTEGER REFERENCES teachers(id),
    day_of_week     INTEGER NOT NULL,               -- 1-5
    shift           VARCHAR(10) NOT NULL,           -- MORNING/EVENING
    semester_id     INTEGER REFERENCES semesters(id),
    UNIQUE(teacher_id, day_of_week, semester_id)
);

-- ========================================
-- 约束配置表
-- ========================================
CREATE TABLE constraints (
    id              SERIAL PRIMARY KEY,
    semester_id     INTEGER REFERENCES semesters(id),
    constraint_code VARCHAR(50) NOT NULL,           -- 如: SHIFT_001, LAYER_001
    constraint_type VARCHAR(20) NOT NULL,           -- HARD/SOFT
    config          JSONB NOT NULL,
    is_enabled      BOOLEAN DEFAULT true,
    weight          INTEGER DEFAULT 5,              -- 软约束权重 1-10
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 四、排课引擎设计

### 4.1 分阶段排课策略

这是解决复杂排课问题的核心方法：**把一个超级复杂的问题分解成多个可解的子问题**。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         排课算法流程                                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  阶段0: 数据预处理与约束检测                                            │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━                                            │
│  ├── 验证数据完整性                                                     │
│  ├── 构建分层组                                                         │
│  ├── 计算教师可用时间                                                   │
│  ├── 检测约束一致性（是否有解）                                         │
│  └── 识别瓶颈资源（声乐教室、钢琴教室等）                               │
│                                                                         │
│  阶段1: 早晚班分配                                                      │
│  ━━━━━━━━━━━━━━━━━━━━                                                  │
│  ├── 根据教师周课时量计算需要的晚班天数                                 │
│  ├── 确保每天有足够晚班教师                                             │
│  ├── 满足班主任约束（周一不晚班、中外互斥）                             │
│  └── 输出: 每位教师每天的班次                                           │
│                                                                         │
│  阶段2: 固定时间预留                                                    │
│  ━━━━━━━━━━━━━━━━━━━━                                                  │
│  ├── 管理干部会议时间（小学周一下午、中学周二下午）                     │
│  ├── 教研组会议时间（各组连续2节）                                      │
│  ├── 游泳课外出时间（NG1周三、NG2周四）                                 │
│  └── 标记这些时间槽为"不可用"                                          │
│                                                                         │
│  阶段3: 分层课排课（最高优先级）                                        │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                          │
│  ├── 按复杂度排序（跨年级 > 同年级，层数多 > 层数少）                   │
│  ├── 为每个分层组寻找可行时间槽                                         │
│  │   └── 检查所有相关教师在该时间的可用性                               │
│  ├── 处理分层课的连堂要求                                               │
```

#### 分层课排课

```python
def schedule_layer_groups(layer_groups, teachers, time_slots):
    """为所有分层组安排时间"""
    
    # 按复杂度排序：跨年级优先，层数多优先
    sorted_groups = sort_by_complexity(layer_groups)
    
    for group in sorted_groups:
        # 获取该分层组的所有教师
        group_teachers = [task.teacher for task in group.tasks]
        # 获取涉及的所有班级
        involved_classes = get_involved_classes(group)
        
        # 找到所有教师同时可用 且 所有班级都没有课的时间槽
        available_slots = []
        for slot in time_slots:
            if all(is_available(t, slot) for t in group_teachers):
                if all(is_free(c, slot) for c in involved_classes):
                    if check_constraints(slot, group):
                        available_slots.append(slot)
        
        # 处理连堂要求
        if group.continuous_required:
            continuous_pairs = find_continuous_pairs(available_slots)
            if not continuous_pairs:
                raise NoSolutionError(f"分层组 {group.id} 无法满足连堂要求")
            
            # 选择最优的连堂时间
            best_pair = select_best_continuous(continuous_pairs)
            schedule_continuous(group, best_pair)
```

#### 全局优化（模拟退火）

```python
def global_optimization(schedule, iterations=1000):
    """模拟退火优化软约束"""
    
    current = schedule
    current_score = evaluate(current)
    best = current
    best_score = current_score
    temperature = 1.0
    
    for i in range(iterations):
        # 生成邻域解
        neighbor = generate_neighbor(current)
        
        # 检查硬约束
        if not satisfies_hard_constraints(neighbor):
            continue
        
        neighbor_score = evaluate(neighbor)
        
        # 接受准则
        if neighbor_score > current_score:
            current = neighbor
            current_score = neighbor_score
            if current_score > best_score:
                best = current
                best_score = current_score
        else:
            # 以一定概率接受较差解
            delta = current_score - neighbor_score
            probability = exp(-delta / temperature)
            if random() < probability:
                current = neighbor
                current_score = neighbor_score
        
        temperature *= 0.995  # 降温
    
    return best
```

### 6.3 状态管理（Pinia）

```javascript
// stores/schedule.js
export const useScheduleStore = defineStore('schedule', {
  state: () => ({
    currentSchedule: null,
    entries: [],
    conflicts: [],
    generating: false,
    generateProgress: 0,
  }),
  
  actions: {
    async generateSchedule(params) {
      this.generating = true;
      this.generateProgress = 0;
      
      // 建立 WebSocket 连接接收进度
      const ws = new WebSocket('/ws/schedule/generate');
      ws.onmessage = (event) => {
        const data = JSON.parse(event.data);
        if (data.type === 'phase_progress') {
          this.generateProgress = data.progress;
        } else if (data.type === 'complete') {
          this.currentSchedule = data.schedule_id;
          this.generating = false;
        }
      };
      
      // 触发生成
      await api.post('/schedules/generate', params);
    },
    
    async swapEntries(entry1Id, entry2Id) {
      const result = await api.post('/schedules/swap', {
        entry1_id: entry1Id,
        entry2_id: entry2Id
      });
      
      if (result.code === 200) {
        // 更新本地状态
        this.refreshEntries();
      }
      
      return result;
    }
  }
});
```
