## 四、测试建议

1. **启动服务**
   ```bash
   # 后端
   cd backend
   .venv\Scripts\activate
   python -m uvicorn app.main:app --reload
   
   # 前端
   cd frontend
   npm run dev
   ```

2. **测试流程**
   - 访问 Dashboard，确认统计数据正确显示
   - 进入数据管理，添加教师、班级、科目
   - 进入行政课程，为班级配置任课教师并保存
   - 进入分层课程，配置分层教学课程并指定每层教师
   - 进入自动排课，确认数据检查显示正确状态
   - 执行排课，查看结果
   - 进入课表管理，测试拖拽调换功能
   - 进入导出课表，测试 CSV 导出
