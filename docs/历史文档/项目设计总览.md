# 排课系统项目设计总览

> 针对复杂约束的分阶段解决方案

## 一、问题复杂度分析

### 1.1 为什么这个排课问题特别难？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           复杂度来源分析                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1️⃣ 分层教学约束 (最难的部分)                                              │
│  ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│  普通排课:  1个班 ←→ 1个老师 ←→ 1个时间槽                                  │
│                                                                             │
│  分层排课:  多个班的学生打乱重组 → 多个层 → 每层1个老师                    │
│            │                                                               │
│            └→ 所有层必须在【同一时间】上课！                               │
│                                                                             │
│  例: G6-G7英语分7层                                                        │
│      → 需要找到一个时间槽，使得7位英语老师同时有空                         │
│      → 而且这个时间槽，G6和G7的所有班级都没有其他课                        │
│      → 每周还要排多节这样的课，还要有连堂！                                │
│                                                                             │
│  2️⃣ 早晚班约束 (动态约束)                                                  │
│  ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│  教师的可用时间不是固定的，取决于当天的班次:                               │
│  - 早班: 全天可排                                                          │
│  - 晚班: 只能排下午（小学）或第5节起（中学）                               │
│                                                                             │
│  而且班次分配本身也有约束:                                                 │
│  - 班主任周一不能晚班                                                      │
│  - 中外班主任不能同天晚班                                                  │
│  - 每天要有足够老师盯晚自习                                                │
│                                                                             │
│  → 排课和排班是【相互依赖】的！                                            │
│                                                                             │
│  3️⃣ 场地容量约束 (全局资源竞争)                                           │
│  ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│  - 体育: 同时≤4班  →  31个班都有体育课，如何分配？                        │
│  - 美术: 同时≤2班  →  小学美术还要连堂！                                  │
│  - 声乐/钢琴: 同时≤1班  →  极度稀缺资源                                   │
│                                                                             │
│  4️⃣ 连堂约束 (时间槽绑定)                                                  │
│  ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│  - 语数英每周至少1次连堂                                                   │
│  - 小学美术必须连堂                                                        │
│  - 分层课也要满足连堂                                                      │
│  - 连堂不能跨午休                                                          │
│                                                                             │
│  5️⃣ 会议时间预留 (批量禁用)                                               │
│  ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│  - 27个教研组，每组要预留2节连续时间                                       │
│  - 小学管理干部周一下午不排                                                │
│  - 中学管理干部周二下午不排                                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 常规方法为什么行不通

| 方法 | 问题 |
|------|------|
| **纯遗传算法** | 分层约束是硬绑定，随机变异99%会违反约束 |
| **纯回溯算法** | 搜索空间太大，分层课导致大量剪枝失败 |
| **整数规划** | 变量数爆炸，求解器超时 |
| **简单贪心** | 前期决策错误，后期无法补救，经常无解 |

## 二、解决方案：分阶段约束满足

### 2.1 核心思想

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         分阶段排课策略                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  核心思想: 把一个超级复杂的问题，分解成多个可解的子问题                     │
│                                                                             │
│  关键洞察:                                                                  │
│  1. 不同约束有不同的"耦合度"                                               │
```

#### 阶段0: 数据预处理

```python
def preprocess():
    """
    目标: 准备数据，检测是否有解
    """
    
    # 1. 构建分层组
    layer_groups = build_layer_groups(teaching_tasks)
    
    # 2. 计算每个分层组需要的"公共可用时间"
    for group in layer_groups:
        teachers = [task.teacher for task in group.tasks]
        # 计算这些教师理论上同时可用的时间槽数量
        common_slots = calculate_common_availability(teachers)
        required_slots = group.weekly_hours
        
        if common_slots < required_slots:
            report_warning(f"分层组 {group.id} 可能无解，可用时间不足")
    
    # 3. 检测场地瓶颈
    for venue in venues:
        total_demand = sum(get_weekly_hours(subject) for subject in venue.subjects)
        max_supply = TOTAL_SLOTS * venue.capacity
        
        if total_demand > max_supply:
            report_error(f"场地 {venue.name} 容量不足")
    
    # 4. 识别"关键教师"（课时多、约束多）
    critical_teachers = identify_critical_teachers(teachers)
    
    return {
        'layer_groups': sorted_by_complexity(layer_groups),
        'critical_teachers': critical_teachers,
        'warnings': warnings
    }
```

#### 阶段1: 早晚班分配

```python
def assign_shifts():
    """
    目标: 为每位教师的每一天分配早班或晚班
    关键: 这决定了教师的可用时间窗口
    """
    
    # 约束
    constraints = [
        # 班主任周一不能晚班
        lambda t, d: not (t.is_cn_homeroom and d == MONDAY and shift == EVENING),
        # 中外班主任不同天晚班
        lambda: not (cn_homeroom.shift[d] == EVENING and en_homeroom.shift[d] == EVENING),
        # 每天晚班教师数 >= 最小值
        lambda d: count_evening_teachers(d) >= MIN_EVENING_TEACHERS,
    ]
    
    # 使用约束传播 + 回溯
    for teacher in teachers:
        # 计算该教师需要上几天晚班（基于课时量和公平性）
        target_evening_days = calculate_target(teacher)
        
        # 寻找可行的晚班安排
        feasible_days = find_feasible_evening_days(teacher, constraints)
        
        # 选择对后续排课影响最小的方案
        selected_days = select_best_evening_days(teacher, feasible_days, target_evening_days)
        
        assign_shifts(teacher, selected_days)
```

#### 阶段3: 分层课排课（核心难点）

```python
def schedule_layer_groups(layer_groups):
    """
    目标: 为所有分层组找到可行的时间安排
    这是最关键的阶段，因为分层课的约束最强
    """
    
    # 按复杂度排序：跨年级 > 同年级，层数多 > 层数少
    # 因为复杂的分层组可选时间更少，应该先安排
    sorted_groups = sort_by_complexity(layer_groups)
    
    scheduled = {}
    
    for group in sorted_groups:
        # 获取该分层组的所有教师
        teachers = [task.teacher for task in group.tasks]
        # 获取涉及的所有班级
        classes = get_involved_classes(group)
        
        # 找到所有教师同时可用，且所有班级都没有课的时间槽
        available_slots = []
        for slot in all_slots:
            if all(is_available(t, slot) for t in teachers):
                if all(is_free(c, slot) for c in classes):
                    if check_constraints(slot, group):  # 其他约束
                        available_slots.append(slot)
        
        # 需要安排的课时数
        hours_needed = group.weekly_hours
        continuous_needed = group.continuous_required
        
        # 如果需要连堂，优先寻找连续的时间槽
        if continuous_needed:
            continuous_pairs = find_continuous_pairs(available_slots)
            if not continuous_pairs:
                raise NoSolutionError(f"分层组 {group.id} 无法满足连堂要求")
            
            # 选择最优的连堂时间
            best_pair = select_best_continuous(continuous_pairs, group)
            schedule_continuous(group, best_pair)
            hours_needed -= 2
            available_slots = remove_used(available_slots, best_pair)
        
        # 安排剩余课时
        if hours_needed > len(available_slots):
            raise NoSolutionError(f"分层组 {group.id} 可用时间不足")
        
        selected_slots = select_best_slots(available_slots, hours_needed)
        for slot in selected_slots:
            schedule_slot(group, slot)
        
        scheduled[group.id] = get_scheduled_slots(group)
    
    return scheduled
```

#### 阶段4: 场地受限课排课

```python
def schedule_venue_limited_courses():
    """
    目标: 安排体育、美术、声乐、钢琴等场地受限课程
    """
    
    # 按场地容量限制排序（容量小的先排）
    # 钢琴(1) = 声乐(1) > 美术(2) > 体育(4)
    venue_order = ['PIANO', 'VOCAL', 'ART', 'PE']
    
    for venue_type in venue_order:
        venue = get_venue(venue_type)
        courses = get_courses_for_venue(venue_type)
        
        for course in courses:
            teacher = course.teacher
            class_ = course.class_
            hours = course.weekly_hours
            is_continuous = course.is_continuous  # 小学美术需要连堂
            
            # 找可用时间槽
            available = []
            for slot in all_slots:
                if is_available(teacher, slot):
                    if is_free(class_, slot):
                        if check_venue_capacity(venue, slot):
                            if check_time_constraints(slot, course):  # 第一节、餐前餐后
                                available.append(slot)
            
            # 处理连堂
            if is_continuous:
                continuous_pairs = find_continuous_pairs(available)
                pairs_needed = hours // 2
                
                for _ in range(pairs_needed):
                    pair = select_best_pair(continuous_pairs)
                    schedule_continuous(course, pair)
                    update_venue_usage(venue, pair)
            else:
                # 逐个安排
                for _ in range(hours):
                    slot = select_best_slot(available)
                    schedule_slot(course, slot)
                    update_venue_usage(venue, slot)
```

```python
def schedule_normal_courses():
    """
    目标: 安排剩余的普通课程（语文、数学、英语非分层部分等）
    此时大部分约束已经满足，相对简单
    """
    
    remaining_courses = get_unscheduled_courses()
    
    # 按优先级排序
    # - 需要连堂的优先
    # - 教师课时多的优先（他们的选择更少）
    sorted_courses = sort_by_priority(remaining_courses)
    
    for course in sorted_courses:
        teacher = course.teacher
        class_ = course.class_
        hours = course.weekly_hours
        
        available = find_available_slots(teacher, class_)
        
        # 处理连堂要求（语数英至少一个连堂）
        if course.needs_continuous:
            continuous_pairs = find_continuous_pairs(available)
            if continuous_pairs:
                pair = select_best_pair(continuous_pairs)
                schedule_continuous(course, pair)
                hours -= 2
                available = remove_used(available, pair)
        
        # 安排剩余课时
        for _ in range(hours):
            # 选择最优时间槽（考虑软约束）
            slot = select_best_slot_with_soft_constraints(available, course)
            schedule_slot(course, slot)
            available.remove(slot)
```

#### 阶段6: 全局优化

```python
def global_optimization(schedule, iterations=1000):
    """
    目标: 在满足硬约束的前提下，优化软约束
    方法: 模拟退火 / 遗传算法
    """
    
    current = schedule
    current_score = evaluate(current)
    best = current
    best_score = current_score
    temperature = 1.0
    
    for i in range(iterations):
        # 生成邻域解
        neighbor = generate_neighbor(current)
        
        # 检查硬约束
        if not satisfies_hard_constraints(neighbor):
            continue
        
        neighbor_score = evaluate(neighbor)
        
        # 接受准则
        if neighbor_score > current_score:
            current = neighbor
            current_score = neighbor_score
            
            if current_score > best_score:
                best = current
                best_score = current_score
        else:
            # 以一定概率接受较差解（避免局部最优）
            delta = current_score - neighbor_score
            probability = exp(-delta / temperature)
            if random() < probability:
                current = neighbor
                current_score = neighbor_score
        
        # 降温
        temperature *= 0.995
    
    return best

def generate_neighbor(schedule):
    """生成邻域解"""
    operations = [
        swap_same_teacher,    # 交换同一教师的两节课
        swap_same_class,      # 交换同一班级的两节课
        move_to_empty_slot,   # 将一节课移到空闲时间
    ]
    
    operation = random.choice(operations)
    return operation(schedule)

def evaluate(schedule):
    """评估课表质量（软约束得分）"""
    score = 0
    
    # 主科上午比例
    morning_ratio = calculate_main_subject_morning_ratio(schedule)
    score += morning_ratio * WEIGHT_MORNING
    
    # 教师空窗期
    teacher_gaps = calculate_teacher_gaps(schedule)
    score -= teacher_gaps * WEIGHT_GAPS
    
    # 每日课时均衡
    daily_balance = calculate_daily_balance(schedule)
    score += daily_balance * WEIGHT_BALANCE
    
    return score
```

## 五、关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 分层课排课 | 优先贪心+回溯 | 约束强，贪心快速找可行解 |
| 普通课排课 | 贪心+优化 | 约束弱，优化空间大 |
| 全局优化 | 模拟退火 | 实现简单，效果好 |
| 约束检查 | 增量更新 | 避免全量检查的性能问题 |
| 班次分配 | 约束传播 | 自动推导不可行方案 |
| 前端状态 | Pinia | 复杂状态管理 |
| 进度反馈 | WebSocket | 实时推送排课进度 |

## 六、风险与应对

| 风险 | 可能性 | 应对措施 |
|------|--------|---------|
| 分层课无解 | 中 | 预处理阶段检测，提前警告 |
| 算法性能差 | 低 | 缓存、剪枝、增量计算 |
| 约束冲突 | 中 | 约束松弛选项，人工干预接口 |
| 需求变更 | 高 | 配置化设计，规则引擎 |
