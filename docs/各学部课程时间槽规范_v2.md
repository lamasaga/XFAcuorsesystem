> **整理日期**: 2026-05-13 | **版本**: v2.0 | **修订说明**: 修正v1.0中的多处时间错误，明确初中/高中共用中学部基础时间槽

## 一、总体架构

学校采用 **两部制基础 + 高中扩展** 的作息时间架构：

| 层级 | 学部 | 代码 | 年级范围 | 每天节次 | 说明 |
|------|------|------|---------|---------|------|
| **基础层** | 小学部 | `PRIMARY` | PK, KG, G1-G5 | 8节 | 独立作息 |
| **基础层** | 中学部 | `SECONDARY` | G6-G12 | 9节（周五8节） | **初中和高中共用** |
| **扩展层** | 高中部扩展 | `SENIOR_EXT` | G10-G12 | +4节（第10-13节） | 仅周一~四 |

> **核心设计原则**：初中（G6-G9）和高中（G10-G12）的第 1-9 节时间安排**完全一致**，差异仅在于高中部在周一~四有额外的第 10-13 节（选修课 + 晚自习）。因此将初中和高中统一纳入 **中学部 (`SECONDARY`)** 基础时间槽管理，高中部在此基础上做扩展。

## 六、两部制基础 + 高中扩展架构说明

### 6.1 为什么初中和高中共用中学部时间槽？

| 对比项 | 初中 (G6-G9) | 高中 (G10-G12) |
|--------|-------------|---------------|
| 周一第1节 | 08:30-09:10 | 08:30-09:10 |
| 周二~四第1节 | 08:10-08:50 | 08:10-08:50 |
| 周五第1节 | 08:10-08:50 | 08:10-08:50 |
| 第1-8节 | 完全一致 | 完全一致 |
| 第9节 | 有 | 有 |
| 第10-13节 | 无 | 有 |

**结论**：初中和高中的第 1-9 节时间安排逐字一致，差异仅在第 10-13 节。将两者统一纳入 `SECONDARY`（中学部）基础时间槽管理，可避免数据冗余，同时通过 `SENIOR_EXT`（高中扩展）标记额外的选修课/晚自习时段。

### 6.2 排课引擎中的应用

```
【时间槽查询逻辑】
if grade in [G6, G7, G8, G9]:
    → 使用 SECONDARY 基础时间槽（第1-9节）

if grade in [G10, G11, G12]:
    → 使用 SECONDARY 基础时间槽（第1-9节）+ SENIOR_EXT 扩展（第10-13节）
    → 或直接使用 SENIOR 完整时间槽（第1-13节）
```

### 6.3 数据库配置建议

**方案A（当前已实现）**：`PRIMARY` / `SECONDARY` / `SENIOR` 三个独立 department
- SENIOR 表中重复存储与 SECONDARY 相同的第1-9节数据
- 优点：查询简单，直接按 department 过滤即可
- 缺点：第1-9节数据冗余（初中和高中各存一份）

**方案B（推荐优化）**：`PRIMARY` / `SECONDARY` / `SENIOR_EXT` 两层架构
- SECONDARY：只存第1-9节（初中和高中共用）
- SENIOR_EXT：只存第10-13节（高中特有）
- 优点：消除冗余，数据一致性更好
- 缺点：查询时需要合并两张表

> **当前状态**：采用方案A（已入库71条数据），后续可评估迁移到方案B。

## 八、对排课系统的关键影响

### 8.1 教师时间约束（跨学部授课）

对于**同时教小学部和中学部**的教师，其不可用时间槽应根据**所教班级所属学部**动态确定：

```
教师教 G3-1（小学部）→ 使用 PRIMARY 时间槽定义
教师教 G7-1（中学部/初中）→ 使用 SECONDARY 时间槽定义
教师教 G11-1（中学部/高中）→ 使用 SECONDARY 基础 + SENIOR_EXT 扩展
```

**核心问题**：当前系统的 `teachers.daily_shifts` 字段没有区分学部，跨学部教师的班次判断存在错误。此问题已通过 `session_department` 参数修复。

### 8.2 A-Level 课程的时间定位

| 优先级 | 时段 | 适用学部 | 说明 |
|--------|------|---------|------|
| P1 | 第 10-11 节 (16:40-18:00) | 高中部 | 标注为"选修课时间"，与行政班正课无冲突 |
| P2 | 第 8-9 节 (15:00-16:30) | 中学部 | 下午时段，可能与部分活动冲突 |
| P3 | 第 6-7 节 (13:15-14:45) | 中学部 | 午后时段，与行政班时间重叠 |

### 8.3 周五的特殊性

| 学部 | 第1节开始 | 放学时间 | 说明 |
|------|----------|---------|------|
| 小学部 | 08:20 | 15:40 | 第8节 15:00-15:40 |
| 中学部（初中+高中） | 08:10 | 15:40 | 第8节 15:00-15:40 |

> 周五小学部比中学部晚开始 10 分钟，但都在 15:40 放学。
