# 各学部课程时间槽规范

> **本文档为排课系统的核心时间配置，来源于 `各学部每节课具体时间.xlsx`。所有排课约束、教师可用时间、学生课表均基于此规范。**
>
> 整理日期: 2026-05-12 | 版本: v1.0

---

## 一、总体架构

学校采用 **三部制** 作息时间，各学部独立定义时间槽：

| 学部 | 代码 | 年级范围 | 每天节次 |
|------|------|---------|---------|
| **小学部** | `PRIMARY` | PK, KG, G1-G5 | 周一 8节 / 周二~四 8节 / 周五 8节 |
| **中学部** | `SECONDARY` | G6-G9 | 周一 9节 / 周二~四 9节 / 周五 8节 |
| **高中部** | `SENIOR` | G10-G12 (A-Level) | 周一~四 11节+2晚自习 / 周五 8节 |

> ⚠️ **关键发现**：三个学部的时间槽**完全不重叠**，特别是小学部和中学部的上课起始时间不同（小学周一 8:40 开始，中学周一 8:30 开始）。这意味着同时跨学部授课的教师，其实际可用时间槽由**所教班级所属学部决定**。

## 七、对排课系统的关键影响

### 7.1 教师时间约束

对于**跨学部授课**的教师（如同时教中学部和高中部），其不可用时间槽应根据**所教班级的学部**动态确定：

```
教师教 IG1-1（小学部）→ 使用小学部时间槽定义
教师教 IG6-1（中学部）→ 使用中学部时间槽定义  
教师教 IG10-1（高中部）→ 使用高中部时间槽定义
```

当前系统的 `teachers.daily_shifts` 和 `unavailable_slots` 字段没有区分学部，这是一个**已知缺陷**。

### 7.2 A-Level 课程的时间定位

根据本规范，A-Level 课程（高中部选修课）的合理排课时段：

| 优先级 | 时段 | 说明 |
|--------|------|------|
| P1 | 第 10-11 节 (16:40-18:00) | 标注为"选修课时间"，与行政班正课无冲突 |
| P2 | 第 8-9 节 (15:00-16:30) | 下午时段，可能与部分行政班活动冲突 |
| P3 | 第 6-7 节 (13:15-14:45) | 午后时段，与行政班时间重叠 |

> 当前 A-Level `schedule_pattern` 预定义时间应优先使用第 10-11 节，这是高中部唯一"无行政班课程"的时段。

### 7.3 周五的特殊性

周五三个学部第 1-8 节**时间完全一致**（08:10-15:40），这意味着：
- 跨学部教师在周五的时间约束是统一的
- 周五是安排跨学部活动的最佳时间
- A-Level 课程如果安排在周五，与行政班的时间冲突风险最低
