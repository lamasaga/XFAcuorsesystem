## ⚠️ 重要约定

### 文档权威性层级

当不同文档之间存在冲突时，按以下优先级判断：

1. **代码本身** — 文档与代码冲突时，以代码为准，并应更新文档
2. **项目现状文档** — 当前系统的权威参考
3. **项目一致性文档** — 字段映射和API定义
4. **业务需求文档**（排课规则规格书）— 业务规则
5. **历史文档** — 仅供参考，**不作为开发依据**

### 新增文档规范

新增文档时请遵循以下命名规范：
- 使用中文名称，反映文档主题
- 技术文档以 `.md` 结尾
- 设计文档建议标注状态：`[已完成]`/`[进行中]`/`[待实施]`
- 及时更新本文档索引
